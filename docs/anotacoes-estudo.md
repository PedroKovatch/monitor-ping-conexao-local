# Anotações de Estudo

## O que é o .gitignore?

O arquivo `.gitignore` informa ao Git quais arquivos e pastas não devem ser adicionados ao histórico do projeto nem enviados ao GitHub.

Ele não exclui nem bloqueia esses arquivos no computador. Apenas evita que sejam enviados ao repositório.
