# Monitor de Conexão Local

## Descrição

O Monitor de Conexão Local é um sistema desktop desenvolvido em Python para acompanhar a conectividade de equipamentos de rede das filiais da empresa.

O sistema permitirá cadastrar manualmente filiais e seus respectivos endereços IP. Em seguida, realizará verificações automáticas de ping e exibirá visualmente o status de cada conexão.

## Objetivo

Facilitar o acompanhamento da disponibilidade de rede das filiais, indicando de forma simples se cada endereço IP está respondendo ou não.

## Tecnologias utilizadas

- Python
- Tkinter
- JSON
- Git
- GitHub
